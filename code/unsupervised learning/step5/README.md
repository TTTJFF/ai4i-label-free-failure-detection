# Step 5 — 完整消融矩阵与 L0 / L1 / L2 标签预算

**状态**：完成（矩阵 8 检测器 × 3 特征集 × 10 个阈值层 = 240 行）
**两个结论**：
1. **step 4 的结论不是三个基线检测器的产物** —— MSV 在 8 个检测器里仍然全面第一（PR-AUC 0.4240 vs 次优 0.2656）。
2. **标签的价值不在"校准阈值"，而在"估计污染率"** —— 用 100 个故障去最大化 F1 会把成绩从 0.3115 打到 0.2271（比不用标签还差）；而用 300 条带标签的**随机**样本估个率，能把成绩推到 **0.4348**（全矩阵最好）。

## 1. 矩阵设计

**8 个检测器**（全部无标签拟合，统一接口）：
Isolation Forest、One-Class SVM、Local Outlier Factor（三个基线）、**Gaussian Mixture**、**Kernel Density**（Scott 带宽）、**Mahalanobis 距离**、**HBOS-style**（逐特征直方图，分数 = −log 分箱概率之和，我们自己的实现，故不称 HBOS）、**MSV**（step 4 的边界违反打分器）。

**3 个特征集**：`F1_raw` / `F2_physics` / `F3_physics_pt`（同 step 1）。

**10 个阈值层**：

| 层 | 含义 | 用了什么 |
|---|---|---|
| `L0 POT 1%` | 极值理论（GPD）尾部拟合，目标触发率 1% | 一个尾部模型假设，无标签、无污染率先验 |
| `L1 ctm=1%` | 训练集分数经验分位 1% | 一个**故意错 3 倍**的弱先验（真值是 3.39%） |
| `Lref ctm=3.39%` | 训练集分数分位 3.39% | 真值（label-derived，故标为参照而非 L0） |
| `L2a F1max N` | 在 N 个故障 + N 个正常样本上**直接最大化 F1** 挑阈值 | N ∈ {10, 20, 50, 100} 个故障标签 |
| `L2b rate from M` | 从 M 条**随机**带标签样本里估**故障率**，再取对应分位 | M ∈ {100, 300, 1000} 条标签，只用来估一个数 |

**注意**：`L2a` 与 `L2b` 的区别是这一步最重要的设计——两者都用标签、都只动阈值、标签都不参与拟合，但用法完全不同，结果也完全相反。

## 2. 结论一：MSV 的优势不是"三个检测器"造成的

物理特征集 F2 上，8 个检测器（阈值无关指标 + 参照操作点）：

| 检测器 | PR-AUC（阈值无关） | F1 @ Lref |
|---|---|---|
| **MSV（边界违反）** | **0.4240** | **0.3832** |
| HBOS-style | 0.2656 | 0.2870 |
| Mahalanobis | 0.2467 | 0.2959 |
| Kernel Density | 0.2229 | 0.2636 |
| Local Outlier Factor | 0.1874 | 0.2545 |
| Isolation Forest | 0.1850 | 0.2439 |
| One-Class SVM | 0.1953 | 0.2150 |
| Gaussian Mixture | 0.1730 | 0.2167 |

两点：

1. **MSV 在两个指标上都是第一**，且领先次优很多（PR-AUC 0.4240 vs 0.2656，+60%）。step 4 的结论**不是**被那三个基线检测器限制出来的产物。
2. **新增的 HBOS-style / Mahalanobis / Kernel Density 也全面超过三个基线**（PR-AUC 0.22–0.27 vs 0.17–0.20）。这独立复现了 step 2/3 的结论：**问题在特征空间，不在检测器。**

原始特征集 `F1_raw` 上，8 个检测器的 PR-AUC 全部落在 0.078–0.185 的窄带里（最好的是 Gaussian Mixture 0.1848）——**换检测器救不了原始特征**。

### 两个必须说明的细节

- **`MSV @ F3 ≡ MSV @ F2`**（数字完全相同）。这是**设计使然**：MSV 定义在约束坐标池（功率/温差/过载/转速）上，按机型标准化并没有改变这个池。所以这一行不是"F3 上的结果"，不要再当作独立证据引用。
- **`MSV @ F1_raw` 明显变差**（PR-AUC 0.1277）。因为原始特征集里没有派生坐标，池回退成"5 个原始传感器的全部单坐标 + 全部两两组合"（15 个子空间）——其中包含与失效无关的坐标。这与 step 4 的敏感性验证（加入转速单坐标导致 F1 崩到 0.1089）是同一个机制：**子空间池的选择本身是一种领域知识，选错会掉分。**

## 3. 结论二：标签到底值多少钱

全矩阵（任意检测器 × 任意特征集）每个阈值层的最好 F1：

| 层 | 用了多少标签 | F1 | Precision | Recall |
|---|---|---|---|---|
| `L0 POT 1%` | **0** | 0.3115 | **0.950** | 0.186 |
| `L1 ctm=1%`（先验错 3 倍） | 0 | 0.3721 | 0.889 | 0.235 |
| `Lref ctm=3.39%`（真值） | 0（但率是标签推出来的） | 0.3832 | 0.366 | 0.402 |
| `L2b rate from M=100` | 100 条随机（约 3 个故障） | 0.3866 | 0.889 | 0.461 |
| **`L2b rate from M=300`** | 300 条随机（约 10 个故障） | **0.4348** | 0.488 | 0.451 |
| `L2b rate from M=1000` | 1000 条随机（约 34 个故障） | 0.3755 | 0.339 | 0.451 |
| `L2a F1max N=10` | 10 个故障 + 10 个正常 | 0.2615 | 0.160 | 0.922 |
| `L2a F1max N=20` | 20 + 20 | 0.2414 | 0.171 | 0.931 |
| `L2a F1max N=50` | 50 + 50 | 0.2736 | 0.170 | 0.902 |
| `L2a F1max N=100` | 100 + 100 | **0.2271** | 0.133 | 0.892 |

### 三条读法

1. **`L2a` 是负结果，而且很重要：用少量标签直接最大化 F1 比不用标签更差。** 从 10 到 100 个故障，F1 全落在 0.227–0.274，**低于零标签的 0.3115**。原因很直白：在 20–200 条样本上最大化 F1，最优解几乎总是"把阈值压得很低、尽量多报"（recall 冲到 0.89–0.93，precision 塌到 0.13–0.17）。**阈值对少量样本严重过拟合。**
2. **`L2b` 是正结果：同样的标签，换成"估计污染率"，收益立刻出现。** M=300 时 F1 = **0.4348**，比零标签的 0.3115 高 0.12；精度从 0.95 降到 0.49，召回从 0.19 升到 0.45——**这是唯一一个把操作点真正搬到合理位置的层。**
3. **先验错 3 倍几乎不要紧。** L1 用 1%（真值 3.39%）只比 Lref 低 0.011。**操作点对污染率的错误相当稳健**，这是一条很实用的结论：你不需要精确知道异常率。

### 一句话总结标签的价值

> **标签的价值不在"校准阈值"（那样做比不用标签还差），而在"估计一个极低维的数（污染率）"。**
> 而真正让 F1 从 0.43 跃到 0.69 的，是**用标签去学习失效机理**（有监督 MLP），不是任何阈值层面的操作——因为校准只能移动操作点，移动不了排序；而 HDF 缺的恰恰是排序里的信息。

## 4. 汇总：无监督方法最终成绩阶梯

| 方法 | F1 | PR-AUC | 标签用量 |
|---|---|---|---|
| 冻结基线最优（OCSVM，原始特征） | 0.2029 | 0.1675 | 0 |
| Step 2 最优（iForest + 物理特征） | 0.2439 | 0.1850 | 0 |
| Step 4 MSV（全子空间，真率操作点） | 0.3832 | 0.4240 | 0 |
| **Step 5 最优（MSV + L2b M=300）** | **0.4348** | 0.4240 | 300 条随机标签 |
| 参照：有监督 MLP | 0.6923 | 0.7471 | 237 个故障（用于**学习**） |
| 参照：规则 + 文档常数 | 0.9263 | — | 0 |

**从 0.2029 到 0.4348，无监督 + 弱标签把 F1 提高了 114%。**

## 5. 局限

1. 单一划分、单次运行，无置信区间。**`L2b` 的 M=100/300/1000 之间差异（0.3866/0.4348/0.3755）是非单调的，应视为噪声范围内的波动，不要挑最高值引用。** 可信的结论是"L2b 明显优于 L2a 与 L0"，而不是"M=300 最优"。
2. `L2a` 采用"在带标签小样本上最大化 F1"这一种朴素协议，把它当作该策略的代表；其他校准目标（例如匹配目标精度）未测试。
3. Kernel Density 的带宽用 Scott 规则、GMM 固定 5 个成分、HBOS-style 分箱约 30 样本/箱——都是固定超参，未做无标签调优。
4. `MSV @ F3` 与 `MSV @ F2` 数字相同（设计使然，见第 2 节），不是独立证据。
5. `Lref` 使用的 3.39% 由标签推出，故全程标注为"参照"而非 L0；真正的零标签结论只能基于 `L0` 与 `L1`。
